# SphericalSAR
This is the code for the paper 'Spherical Spatial Autoregressive Model for Spherically Embedded Spatial Data'

simulation_basic_function.R --- basic functions for simulation

simulation.R --- run simulation studies

real_basic_function.R --- basic functions for real data

real_data_geochemical.R --- real data analysis for geochemical data in Spain

real_data_LTDC.R --- real data analysis for LTDC in Japan
